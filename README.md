# MeuCaixa 2026

Aplicativo PWA de controle financeiro mensal.

## O que já faz
- Entradas e despesas
- Datas de vencimento/recebimento
- Status pendente ou pago/recebido
- Recorrência mensal
- Filtros e busca
- Checklist inteligente das próximas pendências
- Totais por categoria
- Saldo previsto
- Reserva mínima e meta de obra
- Backup e restauração em JSON
- Instalação como aplicativo no Android/desktop via navegador compatível
- Funciona offline depois da primeira abertura

## Como instalar no InfinityFree
1. Envie a pasta inteira para `htdocs/`.
2. Abra o domínio no navegador.
3. No Android/Chrome, use “Adicionar à tela inicial” / “Instalar app”.

## Importante
Esta versão grava os dados no próprio navegador do aparelho (`localStorage`).
Ela é excelente para uso pessoal em um único celular/computador, mas ainda não sincroniza automaticamente entre vários aparelhos.
